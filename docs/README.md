```
docs/
├── screenshot-npanel.png      # N-Panel > KN5 Studio

├── screenshot-export.png     # Export dialog
└── demo.mp4                  # optional short demo
```

Recommended: 1280px PNG, Blender 4.x/5.x UI, example car.
